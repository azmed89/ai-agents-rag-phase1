# Demo — Systeme Multi-Agents Collaboratifs

The Multi-Agent Collaborative System is one of Med's five GenAI demo projects. Several agents collaborate: one researches, one writes, one reviews, for example.

This is multi-agent orchestration. In the roadmap, Phase 2 uses LangGraph for this, because it gives explicit state machines and cycles, preferred for production work in 2026 over looser frameworks.
