# Onessta — affiliate flow

Affiliates register on Onessta, browse the marketplace, and add orders for products they want to sell. They do not handle stock, confirmation, or delivery themselves.

Once an order is added, confirmation agents contact the customer, confirm the order, and pass it to delivery. The affiliate earns a margin-based commission.

Commission is computed at delivery, not at order creation. If the order is not delivered, there is no commission.
