# Demo — Plateforme GenAI avec Modeles Locaux + Cloud Hybride

The GenAI Platform with Local and Cloud Hybrid Models is one of Med's five GenAI demo projects. It runs models locally and in the cloud, choosing where to run each task.

Local models use Ollama and ChromaDB in Med's structured track. Cloud models include OpenAI and Claude. The hybrid approach balances cost, privacy, and latency: local for private data, cloud for heavy reasoning.
