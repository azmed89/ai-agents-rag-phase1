# Demo — Smart Invoice Processor

Smart Invoice Processor is one of Med's five GenAI demo projects. It processes invoices intelligently, extracting structured data from documents.

Related work is the ADI invoice pipeline: in PHP with laravel/ai and laravel-swarm, and in Python with LangChain and CrewAI, at scaffolding stage. The demo shows document understanding plus structured extraction, a classic RAG and agent use case.
